# Redis Streams Producer

The `src/redis-streams/producer.ts` file is a utility script designed to populate a Redis Stream with mock order data. It serves as the entry point for the event-driven workflow, acting as the data source for consumers.

## Purpose
This script automates the ingestion of order events into a Redis Stream named `orders`. It is intended to be used in conjunction with the consumer and recovery scripts to demonstrate stream processing, acknowledgment, and fault tolerance.

## Key Functionality
- **Connection Management**: Establishes a connection to a local Redis instance using the `redis` node client.
- **Stream Ingestion**: Iterates through a range of integers (30–40) and pushes structured objects into the `orders` stream.
- **Data Schema**: Each message added to the stream contains:
    - `orderId`: A unique identifier string.
    - `user`: A user identifier string.
    - `amount`: A string representation of the order value.

## Usage
Ensure you have a Redis server running locally, then execute the script using `ts-node` or by compiling it:

```bash
npx ts-node src/redis-streams/producer.ts
```

## Related Components
This producer is part of a larger Redis Streams implementation:
*   **`consumer.ts`**: Reads and processes the messages generated by this producer using consumer groups.
*   **`inspect.ts`**: Used to monitor pending messages that have not yet been acknowledged.
*   **`recover.ts`**: Handles the re-assignment of stalled or unacknowledged messages to different consumers.
