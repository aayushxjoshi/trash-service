# trash-service

This service is used for just experiments and new learnings.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run <PATH TO THE FOLDER YOU WANNA RUN WITH index.ts>
```

Example:

```bash
bun run src/singleton-pattern/index.ts
```

This project was created using `bun init` in bun v1.3.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
